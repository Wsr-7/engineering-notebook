# Engineering Notebook · 工程手记

一个面向公司内部协作的个人工程门户：用文档、图示和交互页面讲清楚 API 与业务逻辑，同时积累开发笔记、排障经验和工作成果。

**当前状态：前期设计与开发交接文档。网站代码尚未实现，也未部署。**

开发和发布将在公司环境内完成。本 GitHub.com 仓库用于交接通用方案；公司代码、真实业务材料和内部配置在公司仓库中管理。

## 已确定的方向

- **协作优先**：先解决 request/response Schema、调用顺序和状态变化的解释问题。
- **单人维护**：作者与 AI 整理内容，同事只阅读。
- **技术路线**：Astro + Starlight + Pagefind，静态发布，复用文档能力，适度定制门户和展示页。
- **多种表达**：Markdown 知识库、自定义交互讲解、少量独立 HTML/SVG。
- **允许阶段快照**：展示材料可以归档，更新由作者按需要进行。
- **持续积累**：通过项目关联内容，支持日后整理工作总结。
